# 使用前准备

### **设备要求**
- **手机端**
- 使用支持 HiCar 的华为 / 荣耀部分机型；
- 系统建议升级到较新的 HarmonyOS / EMUI 版本；
- 提前打开蓝牙、Wi-Fi、定位权限；
- 建议安装或更新 **HiCar 智行**；

- **车机端**
- 车机需要支持华为 HiCar；
- 原车入口一般叫：HiCar、手机互联、华为 HiCar、智慧互联；
- 部分车型需要在车辆设置里开启手机互联；
- 部分老车机只支持有线连接，不支持无线；

### **连接方式**
- **有线连接**
- 使用数据线连接手机和车机 USB 口；
- 车机选择 HiCar 入口；
- 手机弹出授权后点击允许；
- 首次连接建议使用原装线或支持数据传输的数据线；

- **无线连接**
- 打开手机蓝牙和 Wi-Fi；
- 车机进入 HiCar 页面；
- 手机搜索到车辆后点击连接；
- 首次配对成功后，后续上车可自动连接；

- **扫码连接**
- 车机 HiCar 页面显示二维码；
- 手机打开 HiCar 智行或系统 HiCar 入口；
- 点击扫码连接；
- 按提示完成蓝牙配对和权限确认；

# 手机端

### **HiCar 智行入口**
- 打开 **设置**；
- 进入 **更多连接 / 超级终端 / HiCar 智行**；
- 不同系统版本入口名称可能不一样；
- 找不到入口时，可以在设置顶部搜索 **HiCar**；

### **首次连接流程**
- 手机打开蓝牙、Wi-Fi、定位；
- 车机打开 HiCar；
- 手机选择车辆或扫描车机二维码；
- 确认蓝牙配对码；
- 同意通讯录、电话、通知、位置等权限；
- 车机出现 HiCar 桌面后表示连接成功；

<span style="color:red">注：首次连接不要一直点返回，权限弹窗要确认，不然后面容易出现电话、导航、音乐异常；</span>

### **车辆管理**
- 打开 **HiCar 智行**；
- 进入 **我的车辆 / 连接管理**；
- 可以查看已经绑定的车辆；
- 可以删除旧车辆重新配对；
- 可以开启或关闭自动连接；
- 换车机、换手机、升级系统后，建议删除旧记录重新连接；

### **权限管理**
- **蓝牙权限**：用于车辆配对和自动连接；
- **Wi-Fi 权限**：用于无线投屏和数据传输；
- **定位权限**：用于导航、车辆发现、附近设备识别；
- **电话权限**：用于车机拨打和接听电话；
- **通讯录权限**：用于车机显示联系人；
- **通知权限**：用于车机显示消息提醒；
- **麦克风权限**：用于语音输入和小艺语音；

# 设置面板

### **连接设置**
- **自动连接**
- 开启后，上车启动车机自动尝试连接 HiCar；
- 如果经常连错车，可以关闭后手动连接；
- 如果连接不稳定，可以删除车辆后重新配对；

- **优先连接**
- 多台手机都绑定过车辆时，建议只保留常用手机；
- 家里多人共用车辆时，谁先连接蓝牙，谁更容易被车机识别；
- 车机端如果有设备列表，可以把常用手机设为优先；

- **有线 / 无线切换**
- 有线更稳定，适合长途导航；
- 无线更方便，适合日常通勤；
- 无线卡顿时，可临时改用有线；

### **导航设置**
- **默认导航**
- 可按习惯选择高德地图、百度地图、华为地图等；
- 手机端设置默认地图后，车机点击地址会优先打开对应地图；
- 如果车机不显示地图，先确认地图 App 已安装并允许联网；

- **路线同步**
- 手机上提前搜索目的地；
- 连接 HiCar 后，路线可在车机端继续使用；
- 微信、短信里的地址，可复制后再打开地图导航；

- **导航声音**
- 可在地图 App 内调整播报音量；
- 可在车机音量里调整媒体 / 导航 / 蓝牙通话音量；
- 如果只有画面没有声音，优先检查车机音源是否切到 HiCar；

### **音乐设置**
- **默认音乐 App**
- 可使用华为音乐、QQ 音乐、网易云音乐等支持车机显示的应用；
- 连接后在车机音乐卡片里播放和切歌；
- 如果列表不刷新，先在手机端打开一次音乐 App；

- **声音输出**
- 一般通过车机音响播放；
- 如果声音还在手机上，检查蓝牙音频是否连接；
- 如果声音很小，分别调整手机音量和车机媒体音量；

### **电话设置**
- **来电提醒**
- 允许电话和通讯录权限后，车机可显示来电；
- 可在车机屏幕点击接听或挂断；
- 通话声音一般走车机蓝牙；

- **联系人显示**
- 通讯录不显示时，重新授权通讯录权限；
- 部分车机需要在蓝牙设置里开启同步联系人；
- 如果联系人乱码或缺失，删除蓝牙配对后重新连接；

### **语音设置**
- **小艺语音**
- 可在车机端唤起语音；
- 支持导航、打电话、播放音乐等常用操作；
- 使用前确认麦克风权限已允许；

- **语音唤醒**
- 部分车型支持方向盘按键唤醒；
- 部分车型支持车机按钮唤醒；
- 不能唤醒时，先看车机是否占用了语音按键；

### **应用管理**
- **车机可用应用**
- HiCar 车机端只显示适配的应用；
- 手机里安装了，不代表车机一定显示；
- 需要更新 App 到新版本后再试；

- **应用排序**
- 常用导航、音乐、电话建议放前面；
- 不常用应用可以放后面；
- 部分车机支持长按拖动排序；

# 车机端

### **首页操作**
- 点击 HiCar 图标进入桌面；
- 点击导航卡片进入地图；
- 点击音乐卡片播放音乐；
- 点击电话入口拨打电话；
- 点击应用列表查看更多 App；

### **方向盘按键**
- 上一曲 / 下一曲：切换音乐；
- 音量 + / -：调整车机音量；
- 语音键：唤起语音助手；
- 电话键：接听或挂断电话；
- 不同车型按键映射可能不同，以车机实际为准；

### **返回原车机**
- 点击车机上的返回、主页或车辆按键；
- 部分车机 HiCar 页面有退出按钮；
- 退出 HiCar 后，手机不会断开蓝牙通话；
- 想完全断开，可以在手机通知栏或 HiCar 智行里断开；

# 常见问题

### **连接不上**
- 检查车机是否支持 HiCar；
- 检查手机蓝牙、Wi-Fi、定位是否打开；
- 删除手机端车辆记录后重新配对；
- 删除车机端手机记录后重新配对；
- 更换数据线或 USB 接口；
- 重启手机和车机后再试；

### **不能自动连接**
- 确认 HiCar 智行里开启自动连接；
- 确认手机没有省电限制 HiCar 智行；
- 确认车机蓝牙没有连到其他手机；
- 多台手机同时上车时，先关闭不用手机的蓝牙；

### **有画面没声音**
- 检查车机音源是否切到 HiCar / 蓝牙；
- 检查手机媒体音量是否过低；
- 检查车机媒体音量是否过低；
- 重新打开音乐 App；
- 断开蓝牙后重新连接；

### **导航没有声音**
- 打开地图 App 的导航播报；
- 检查地图是否静音；
- 检查车机导航音量；
- 播放音乐时，导航声音可能会被压低；

### **应用不显示**
- 车机端只显示 HiCar 适配应用；
- 更新手机系统、HiCar 智行、对应 App；
- 卸载后重新安装 App 再试；
- 部分 App 需要打开一次后才会出现在车机端；

### **无线卡顿**
- 手机尽量靠近车机；
- 关闭热点、投屏、下载等占用网络的操作；
- 长途导航建议使用有线连接；
- 车机系统太旧时，建议咨询厂家升级固件；

# 推荐设置

### **新手推荐**
- 连接方式：优先有线，稳定后再试无线；
- 默认地图：设置自己常用的地图；
- 默认音乐：设置自己常用的音乐 App；
- 自动连接：常用车辆建议开启；
- 通知权限：只打开必要应用，避免消息太多；

### **日常通勤**
- 上车自动连接；
- 车机首页保留导航和音乐；
- 手机提前打开蓝牙和 Wi-Fi；
- 常用目的地提前收藏；
- 地图和音乐 App 保持后台可用；

### **长途导航**
- 建议使用有线连接；
- 出发前更新离线地图或检查网络；
- 手机保持充电；
- 音量提前调好；
- 重要路线不要边开车边设置；
