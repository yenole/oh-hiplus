# Hi时刻和HiCar模式怎么选

最近有不少车友第一次使用时，会问一个问题：

**Hi时刻里面有两个模式，一个是 Hi时刻，一个是 HiCar，到底有什么区别？**

这篇简单说明一下。

先说结论：

- **Hi时刻模式**：走 Hi时刻自己的车机端和投屏桌面，也支持 HiCar 通道，需要配置 Shizuku 权限，入门门槛相对高一点；
- **HiCar模式**：给原车 HiCar 做拓展，用来打开 HiCar 原本不支持的应用；
- 想用 Dock栏、应用栏、壁纸、窗口模式，并且愿意配置 Shizuku，优先看 **Hi时刻模式**；
- 原车或盒子已经能进入 HiCar，想在 HiCar 里打开更多应用，优先看 **HiCar模式**；

# 模式说明

### **Hi时刻模式**

- **Hi时刻模式**
- 配合 **Hi时刻手机端 + Hi时刻车机端** 使用；
- 支持默认通道；
- 支持 HiCar 通道；
- 主要用于自定义车机桌面；
- 支持 Dock栏、应用栏、音乐栏、通知栏；
- 支持壁纸、主题、布局调整；
- 支持应用全屏、悬浮、填充显示；
- 支持任务计划、快捷功能、手势等玩法；
- 需要配置 Shizuku 权限；
- 入门门槛相对高一点；
- 更适合愿意折腾车机桌面的车友；

简单说：

> Hi时刻模式，就是把手机里的常用应用和功能，整理成适合车机屏幕使用的方式，可以走默认通道，也可以走 HiCar 通道。

比如：

- 地图全屏显示；
- 音乐悬浮显示；
- Dock栏放常用应用；
- 上车自动打开音乐；
- 车机端显示通知和播放状态；
- 自己调整壁纸和布局；

### **HiCar模式**

- **HiCar模式**
- 用于支持 **HiCar** 的车机或盒子；
- 不是重新做一套车机桌面；
- 主要是给原车 HiCar 做拓展；
- 用来打开 HiCar 原本不支持的应用；
- 支持应用通知显示；
- 支持覆盖首页的音乐卡片；
- 支持小窗应用等拓展能力；
- 比如部分音乐、地图、视频、工具类应用；
- 部分功能会受手机、车机、盒子版本影响；
- 不同车型、不同盒子体验可能不一样；
- 更适合已经有 HiCar 环境的车友；

简单说：

> HiCar模式，就是在原车 HiCar 的基础上，拓展打开更多应用，并补充通知、音乐卡片、小窗应用等能力。

比如：

- 原车支持 HiCar；
- 使用 HiCar 盒子；
- 已经可以正常进入 HiCar；
- 想在 HiCar 里打开更多应用；
- 想使用 HiCar 原本不支持的应用；
- 想在 HiCar 中显示应用通知；
- 想覆盖首页音乐卡片；
- 想使用小窗应用；

# 怎么选择

### **优先选择 Hi时刻模式**

如果你是下面这些情况，建议先用 **Hi时刻模式**：

- 能接受配置 Shizuku 权限；
- 愿意按教程一步一步设置；
- 想用 Hi时刻车机端；
- 想通过默认通道或 HiCar 通道使用 Hi时刻桌面；
- 想自定义车机桌面；
- 想要 Dock栏；
- 想要应用栏；
- 想要音乐栏；
- 想设置壁纸；
- 想调整布局；
- 想让应用全屏、悬浮、填充显示；
- 想用任务计划自动打开应用；

适合人群：

- 喜欢自定义车机界面；
- 能接受一定配置门槛；
- 不怕按教程配置 Shizuku；
- 想把手机应用搬到车机上用；
- 原车车机应用少；
- 原车系统不太好用；
- 想要更灵活的显示方式；

### **优先选择 HiCar模式**

如果你是下面这些情况，建议先看 **HiCar模式**：

- 原车支持华为 HiCar；
- 正在使用 HiCar 盒子；
- 手机和车机可以正常进入 HiCar；
- 想在 HiCar 里打开更多应用；
- 想打开 HiCar 原本不支持的应用；
- 想显示应用通知；
- 想覆盖首页音乐卡片；
- 想使用小窗应用；
- 主要需求是拓展 HiCar 应用范围；

适合人群：

- 华为手机用户；
- 原车支持 HiCar 的车友；
- 使用 HiCar 盒子的车友；
- 已经习惯 HiCar 使用方式的车友；

# 手机端通道说明

### **Hi时刻**

- **默认**
- 配合 Hi时刻车机端使用；
- 走 Hi时刻默认通道；
- 需要 Shizuku 权限支持；
- 适合愿意按教程配置的新用户；
- 第一次使用建议先选这个；
- 按教程完成权限和连接即可；

- **无线**
- 部分场景下使用；
- 群主自测使用较多；
- 不建议新用户一上来就选择；

- **互联 / HiCar通道**
- Hi时刻模式也支持 HiCar 通道；
- 可用于通过 HiCar 环境显示 Hi时刻桌面；
- 智驾、开发协议相关能力合并到这里；
- 部分 HiCar 或互联场景可能会用到；
- 需要根据车型和手机环境测试；

- **自测**
- 用于手机端测试效果；
- 适合排查或测试显示；
- 普通用户一般不用管；

### **HiCar**

- **HiCar**
- 面向 HiCar 车机或盒子场景；
- 给原车 HiCar 拓展更多应用；
- 用于打开 HiCar 原本不支持的应用；
- 支持应用通知显示；
- 支持覆盖首页音乐卡片；
- 支持小窗应用；
- 前提是车机或盒子本身可以正常进入 HiCar；
- 具体效果和设备环境有关；

# 两个模式的区别

### **连接对象不同**

- **Hi时刻模式**
- 主要连接 Hi时刻车机端；
- 手机端和车机端配合使用；
- 可走默认通道；
- 也可走 HiCar 通道；
- 车机端显示 Hi时刻桌面；

- **HiCar模式**
- 主要面向 HiCar 环境；
- 依赖车机或盒子对 HiCar 的支持；
- 在原车 HiCar 基础上拓展应用；
- 用于打开 HiCar 原本不支持的应用；
- 支持应用通知、音乐卡片、小窗应用等能力；

### **功能方向不同**

- **Hi时刻模式**
- 更偏自定义；
- 更偏桌面管理；
- 支持默认通道和 HiCar 通道；
- 更偏应用投屏；
- 更偏窗口玩法；

- **HiCar模式**
- 更偏 HiCar 拓展；
- 更偏打开更多应用；
- 更偏应用通知显示；
- 更偏音乐卡片覆盖；
- 更偏小窗应用；
- 更偏 HiCar 应用兼容；
- 更偏已有 HiCar 环境；

### **适配差异不同**

- **Hi时刻模式**
- 主要看手机端、车机端、权限配置；
- 其中 Shizuku 权限是入门重点；
- 权限正确后，功能相对更可控；

- **HiCar模式**
- 还会受到车机、盒子、系统版本影响；
- 同样是 HiCar，不同设备体验可能不一样；

# 新用户建议

### **第一次使用**

- 先不要纠结太多；
- 先确认自己有没有 HiCar 环境；
- 有 HiCar 车机或盒子，可以先看 HiCar模式；
- 没有 HiCar 环境，再考虑 Hi时刻模式；
- Hi时刻模式需要配置 Shizuku，入门门槛相对高一点；
- 第一次使用建议使用默认配置；
- 能正常连接后，再调整壁纸、布局、应用；

### **推荐顺序**

如果你不知道怎么选，可以按下面顺序来：

- 第一步：确认车机是否支持 HiCar；
- 第二步：确认是否使用 HiCar 盒子；
- 第三步：如果有 HiCar 环境，优先选择 **HiCar模式**；
- 第四步：如果没有 HiCar 环境，并且能接受 Shizuku 配置，再选择 **Hi时刻模式**；
- 第五步：遇到问题，再公众号留言说明设备环境；

# 常见问题

### **我没有 HiCar，可以用 Hi时刻吗**

- 可以；
- 没有 HiCar 环境，可以优先使用 Hi时刻模式；
- Hi时刻模式主要配合 Hi时刻车机端使用；

### **我有 HiCar，还能用 Hi时刻吗**

- 可以；
- 但是要看你的使用目的；
- 想在 HiCar 里打开更多应用，就看 HiCar模式；
- 想要应用通知、音乐卡片、小窗应用，也看 HiCar模式；
- 想用 Dock栏、窗口、壁纸，就看 Hi时刻模式；

### **两个模式可以同时用吗**

- 不建议新用户同时折腾；
- 先把一个模式跑通；
- 再根据需求切换测试；
- 同时调整太多，出问题不方便判断；

### **为什么别人能用，我这里不行**

- 手机型号不同；
- 系统版本不同；
- 车机版本不同；
- 盒子版本不同；
- 权限配置不同；
- 后台限制不同；

<span style="color:red">所以反馈问题时，一定要说明手机、系统、车机、盒子和选择的模式；</span>

# 最后总结

### **一句话区分**

- **Hi时刻模式**：自定义车机桌面，主打 Dock栏、应用栏、窗口、壁纸、任务计划，支持默认通道和 HiCar 通道，需要配置 Shizuku；
- **HiCar模式**：面向 HiCar 车机或盒子，主打拓展打开 HiCar 原本不支持的应用，同时支持应用通知、音乐卡片、小窗应用；

### **怎么选**

- 想折腾车机桌面，并且能接受 Shizuku 配置：选 **Hi时刻模式**；
- 想在 HiCar 里打开更多应用：选 **HiCar模式**；
- 想要应用通知、音乐卡片、小窗应用：选 **HiCar模式**；
- 不知道怎么选：先确认有没有 HiCar 环境；
- 没有 HiCar 环境：再考虑 **Hi时刻模式**；
- 有 HiCar 车机或盒子：优先看 **HiCar模式**；
