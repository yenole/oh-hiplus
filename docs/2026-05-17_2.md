# 纯血鸿蒙使用 HDC 获取设备 UDID

在纯血鸿蒙（HarmonyOS NEXT）开发调试中，如果需要获取设备 UDID，可以通过 `hdc` 命令完成。

## 前提条件

- 已安装 DevEco Studio 或 HarmonyOS SDK
- 已配置 `hdc` 环境变量
- 设备已开启开发者模式
- 设备已开启 USB 调试
- 电脑已连接鸿蒙设备

## 获取 HDC 工具

`hdc` 是 HarmonyOS 提供的命令行调试工具，可以单独下载，也可以随 DevEco Studio 或 HarmonyOS SDK 一起安装。

官方文档参考：

```text
https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/hdc
```

### 方式一：通过 DevEco Studio 获取

访问华为开发者官网，下载并安装 DevEco Studio：

```text
https://developer.huawei.com/consumer/cn/deveco-studio/
```

安装完成后，通过 DevEco Studio 下载 HarmonyOS SDK。`hdc` 通常位于 HarmonyOS SDK 的 `toolchains` 目录下。

### 方式二：通过 SDK Manager 获取

如果已经安装 DevEco Studio，可以打开 SDK Manager：

```text
DevEco Studio -> Settings -> SDK -> HarmonyOS SDK
```

检查是否已安装对应版本的 SDK Tool。安装完成后，即可在 SDK 目录的 `toolchains` 目录中找到 `hdc`。

### 方式三：直接下载 HDC

如果只是需要使用命令行连接设备，可以到华为开发者下载页面查找 HDC 工具：

```text
https://developer.huawei.com/consumer/cn/download/
```

进入页面后，搜索 `HDC` 或在工具下载区域中找到对应的 HDC 工具，按自己的系统选择 macOS、Windows 或 Linux 版本下载。下载并解压后，将 `hdc` 所在目录配置到系统环境变量中即可使用。

### 配置环境变量

如果终端无法直接使用 `hdc`，需要将 `hdc` 所在目录配置到系统环境变量中。

macOS 常见路径示例：

```bash
~/Library/Huawei/Sdk/openharmony/toolchains
```

Windows 常见路径示例：

```text
C:\Users\<用户名>\AppData\Local\Huawei\Sdk\openharmony\toolchains
```

配置完成后，执行以下命令验证：

```bash
hdc -v
```

如果能正常输出版本号，说明 `hdc` 已可用。

如果以上路径或安装入口发生变化，以华为 HDC 官方文档为准。

## 获取 UDID

连接设备后，在终端执行：

```bash
hdc shell bm get --udid
```

执行后会返回当前连接设备的 UDID。

## 多设备场景

如果电脑连接了多台设备，先查看设备列表：

```bash
hdc list targets
```

然后指定设备执行：

```bash
hdc -t <设备ID> shell bm get --udid
```

示例：

```bash
hdc -t 127.0.0.1:5555 shell bm get --udid
```

## 常见问题

如果提示找不到设备，可以尝试重启 HDC：

```bash
hdc kill
hdc start
hdc list targets
```

同时检查 USB 数据线、USB 调试授权、开发者模式以及 `hdc` 环境变量是否正常。

## 总结

获取设备 UDID 的核心命令是：

```bash
hdc shell bm get --udid
```

多设备时使用：

```bash
hdc -t <设备ID> shell bm get --udid
```

## 后续可能开发：网页获取 UDID

后续可以考虑提供一个面向测试用户的网页入口，用于引导用户获取设备 UDID 并提交设备登记信息。Hi 时刻的安装入口可作为后续能力预留，不作为该流程的主要目标。

### 目标

- 降低测试用户手动使用 `hdc` 获取 UDID 的门槛
- 统一收集设备 UDID、用户联系方式、设备型号等测试登记信息
- 减少人工通过聊天工具收集 UDID 的成本
- 为后续测试授权、安装引导等流程预留扩展空间

### 可能流程

1. 用户在鸿蒙设备浏览器中打开测试登记网页。
2. 网页展示测试说明、隐私说明和安装前提。
3. 用户按页面引导获取设备 UDID。
4. 用户提交 UDID、联系方式、设备型号、系统版本等信息。
5. 后台保存登记信息，并提示等待审核或授权。
6. 管理员将 UDID 加入测试设备名单或完成对应发布配置。
7. 授权完成后，网页可以提示用户当前设备已完成登记。
8. 如后续需要，也可以在页面中补充测试说明或安装引导入口。

### UDID 获取方式

网页获取 UDID 可以基于无线调试方式实现。网页本身不直接读取系统级设备 UDID，而是通过页面引导用户开启设备无线调试，并由服务端或本地工具使用 `hdc` 连接设备后执行 UDID 查询命令。

可能流程如下：

1. 用户在鸿蒙设备上打开测试登记网页。
2. 网页提示用户开启开发者模式和无线调试。
3. 用户在设备无线调试页面查看配对码、IP 地址和端口。
4. 用户将配对信息填写到网页中。
5. 后台或本地服务通过 `hdc` 使用无线调试信息连接设备。
6. 连接成功后执行 `hdc shell bm get --udid` 获取设备 UDID。
7. 网页将获取到的 UDID 自动填入登记表单，用户确认后提交。

无线调试连接示例：

```bash
hdc tconn <设备IP>:<端口>
hdc shell bm get --udid
```

如果存在配对步骤，则需要根据设备无线调试页面展示的信息先完成配对，再进行连接。具体命令以当前 HarmonyOS NEXT 和 HDC 版本支持的无线调试能力为准。

这种方式的重点是：用户不需要通过 USB 连接电脑，也不需要手动在终端执行完整命令；网页负责提供清晰步骤，后台或本地服务负责完成无线调试连接和 UDID 查询。

实际开发前需要确认 HarmonyOS NEXT 对无线调试配对、局域网访问、HDC 命令执行环境、浏览器到本地服务通信的限制，避免设计出无法落地的流程。

### 后续扩展

UDID 登记流程稳定后，可以再根据实际测试分发方式补充 Hi 时刻相关引导。该部分建议保持轻量，不在第一阶段强绑定具体安装方式。

- 展示设备登记和授权状态
- 展示测试说明、版本说明或注意事项
- 在具备条件时提供安装引导入口
- 对未授权设备提示等待审核或补充登记信息

### 页面能力建议

- 登记表单：收集 UDID、姓名或昵称、联系方式、设备型号、系统版本、备注
- 状态查询：用户输入手机号、邮箱或登记编号后查询审核和授权状态
- 后续引导：按当前设备状态展示下一步操作，不让用户自行判断流程
- 问题排查：提供无法获取 UDID、无法安装、安装后无法打开等常见问题说明
- 后台管理：支持查看登记列表、标记审核状态、记录授权时间和安装版本

### 注意事项

- UDID 属于设备标识信息，收集前需要明确告知用途、保存周期和删除方式
- 网页应使用 HTTPS，避免设备标识和联系方式明文传输
- 后台需要限制访问权限，避免测试设备信息泄露
- 如后续提供安装入口，应控制访问范围，避免未授权用户直接访问
- 如果依赖官方测试分发能力，应以华为最新文档和审核规则为准
