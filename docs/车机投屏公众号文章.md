# 车机投屏

### **基础说明**

- **车机投屏**
- 字面意思：手机连接车机，把常用功能显示到车机屏幕；
- 实际体验：不是简单镜像手机屏幕；
- 常用功能：导航、音乐、电话、消息、语音助手；
- 使用目的：减少开车时拿手机的次数；
- 操作方式：触控、方向盘按键、语音指令配合使用；

- **常见方案**
- Apple CarPlay：苹果用户使用比较多；
- 华为 HiCar：华为手机和部分车机适配；
- Android Auto：安卓生态投屏方案；
- 百度 CarLife：国内不少车型支持；
- 车企互联：各家车企自己的手机互联系统；
- 第三方盒子：用于无线CarPlay或协议转换；

- **注**：成熟的车机投屏，不是把手机完整画面复制到中控屏；
- 如果只是完整镜像，开车时反而容易分心；
- 更合理的方式，是把界面重新适配驾驶场景；
- 比如：按钮更大、层级更少、信息更清楚、语音占比更高；

### **为什么需要投屏**

- **手机生态**
- 地图更新快；
- 音乐内容全；
- 账号数据完整；
- 联系人、日程、常去地点都在手机里；
- 每天都在使用，学习成本低；

- **车机问题**
- 部分车机应用少；
- 应用版本旧；
- 反应速度慢；
- 账号需要重新登录；
- 操作逻辑和手机不一样；

- **用户感受**
- 上车后不想重新适应一套系统；
- 不想重新找收藏地点；
- 不想重新整理歌单；
- 不想一边开车一边低头看手机；

所以投屏的价值很直接：
- 手机负责内容和服务；
- 车机负责显示和车内交互；
- 两边配合，使用更顺手；

# 使用场景

### **导航**

- **手机地图优势**
- 路况更新快；
- 搜地址更准；
- 收藏地点都在手机里；
- 历史记录不用重新找；
- 账号数据可以同步；
- 避堵和路线规划更成熟；

- **投屏后效果**
- 路线显示到中控屏；
- 路口提示更清楚；
- 预计到达时间更直观；
- 不用频繁低头看手机；
- 去陌生地方或跑长途更省心；

- **通勤场景**
- 早上上车：可能自动推荐去公司路线；
- 晚上下班：可能自动推荐回家路线；
- 遇到堵车：可以快速切换路线；

### **音乐**

- **常用内容**
- QQ音乐；
- 网易云音乐；
- Apple Music；
- 喜马拉雅；
- 播客、有声书；

- **主要体验**
- 会员不用重新开；
- 歌单不用重新搬；
- 收藏不用重新整理；
- 上车后继续听自己的内容；

- **重点**
- 不是车里能不能放歌；
- 而是自己的内容能不能跟着自己走；

### **电话和消息**

- **电话**
- 可以在车机上接听；
- 可以通过语音助手拨号；
- 可以配合方向盘按键操作；
- 少拿一次手机，就少一次分心；

- **消息**
- 部分系统支持播报消息；
- 支持简单语音回复；
- 比如：“我在开车，稍后联系”；
- 不建议在开车时处理复杂内容；

### **语音助手**

- **常用指令**
- 导航到公司；
- 播放我喜欢的歌；
- 打电话给家人；
- 回家路况怎么样；
- 切换下一首；

- **说明**
- 开车时，语音比手点更适合；
- 能语音完成的操作，尽量不要手动点屏幕；
- 注意力还是要放在路上；

# 体验问题

### **无线连接**

- **常见问题**
- 上车不自动连接；
- 连接后突然断开；
- 画面黑屏；
- 操作延迟；
- 声音延迟；
- 导航卡顿；

- **有线连接**
- 稳定性一般更好；
- 但每次上车都要插线；
- 便利性不如无线；

- **实际感受**
- 无线很方便；
- 但偶尔会掉链子；
- 有线更稳定；
- 但少了一点无感连接的体验；

### **车型差异**

- **影响因素**
- 屏幕比例；
- 触控响应；
- 音频延迟；
- 方向盘按键适配；
- 仪表盘能不能联动；
- HUD能不能显示导航；
- 车机系统本身是否稳定；

- **注**：支持投屏，不等于投屏好用；
- 同样是CarPlay，不同车上的体验可能完全不一样；
- 买车时最好实际连接试一下；

### **应用限制**

- **限制类型**
- 视频类应用不适合完整开放；
- 社交类应用不适合复杂操作；
- 游戏类应用不适合驾驶场景；

- **原因**
- 不是单纯限制用户；
- 主要是为了驾驶安全；
- 车机投屏的核心是服务驾驶，不是把中控屏变成娱乐场所；

# 原生车机

### **车辆控制**

- **原生车机负责**
- 空调；
- 座椅；
- 驾驶模式；
- 车辆设置；
- 能耗信息；
- 辅助驾驶状态；

- **手机投屏负责**
- 导航；
- 音乐；
- 电话；
- 消息；
- 语音助手；
- 常用应用生态；

- **关系说明**
- 投屏不能完全替代原生车机；
- 原生车机也不一定要排斥投屏；
- 更合理的方式是分工合作；

# 智能座舱

### **现在的变化**

- 新能源车机进步很快；
- 芯片更强；
- 屏幕更大；
- 语音助手更聪明；
- 应用生态比以前丰富；
- 很多新车已经不是以前那种卡、慢、难用的车机；

### **投屏是否还重要**

- **依然重要**
- 因为手机仍然是数字生活中心；
- 通讯录在手机里；
- 音乐偏好在手机里；
- 地图收藏在手机里；
- 日程和常用App也在手机里；

- **说明**
- 车机可以越来越强；
- 但很难完整复制手机生态；
- 对用户来说，开放、兼容、顺手同样重要；

# 未来方向

### **连接入口**

- 手机上提前选好目的地，上车后自动同步到车机；
- 日程里的地点自动变成导航建议；
- 车机根据通勤习惯推荐路线；
- 车机根据使用习惯推荐音乐；
- 手机App读取部分车辆状态；
- 中控屏、仪表屏、HUD之间分配不同信息；

### **角色变化**

- 过去：投屏更多是在弥补车机不好用；
- 现在：投屏连接手机生态和车内场景；
- 以后：投屏可能会成为手机和汽车之间的服务入口；

- **总结**
- 投屏不只是显示手机内容；
- 更像是手机和汽车之间的一条通道；

# 写在最后

- 车机投屏的价值，不是把手机原封不动搬到车上；
- 它解决的是一个很具体的问题；
- 车机有时候不够顺手；
- 手机又不能直接拿着用；
- 投屏刚好在中间搭了一座桥；

### **对车主**

- 导航更自然；
- 音乐更顺手；
- 电话更方便；
- 消息处理更克制；
- 开车时少拿几次手机；

### **对车企**

- 智能座舱不只是屏幕大小；
- 不只是芯片算力；
- 也不是功能越多越好；
- 最后还是要看用户用起来顺不顺；

汽车正在变成越来越重要的智能终端；

而车机投屏，就是手机和汽车之间最容易被感知到的连接方式之一；
