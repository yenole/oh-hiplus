# 手机端

### **用户信息**

- **授权登录**
- 长按弹出授权框；
- 点击头像可刷新、退出操作；
- 点击复制授权框；
- 发送至公众号，并提示绑定成功；
- 点击授权激活用户模式；
- 会根据打赏文章映射会员级别；
- **用户面板**
- 点击头像进入；
- 显示昵称、头像、会员、到期时间； 
- 显示账号权限，<span style="color:red">点击刷新会刷新用户信息；</span>

- **会员级别**
- SVIP：新功能优先体验；
- VIPX：会根据级别体验相关功能；
- 体验：开通体验权限，时长一般2天； 
- 粉丝：目前可使用HiCar（旧）、默认协议投屏；

### **通道选择**
-  Hi时刻
	-  **通道协议**
	- 默认：配合车机端（暗号：车机）；
    - 无线：群主自测使用；
	- 互联：智驾+开发协议（HiCar）；
	- 自测：用于手机测试效果和其他互联；
	- 需要联系开发者开启权限；
-  HiCar：迁移老版本投屏效果；

### **运行环境**
- Shizuku权限：由于新版投票需要较高的权限；
- 通知使用权：用户车机显示通知和音乐使用；
- 悬浮框权限：投屏后防止手机锁屏和HiCar需要；
- 麦克风权限：语音输入和语音指令需要的权限； 
- 读日记权限：用于读取HiCar日记，特定功能需要；

### **任务计划**
- 启动：投屏后触发；
	- 比如：打开音乐软件；
- 断开：断开连接触发；
	- 比如：关闭**Hi时刻**；
- 地图：录入高德分享的地址；
	- 用于地图快捷导航；

### **版本信息 & 订阅号**
- 显示版本信息;
- 显示订阅号名称；
- **右侧图标信息**
- 右侧“刷新”图标：提示更新应用；
- 右侧“感叹号”图标：复制崩溃信息；

# 设置面板
### **自启配置**
- **Hi时刻**    
- 选定蓝牙设备后，链接自动投屏；
- **互联**
- 开启后，连接适配的互联后会自动投屏；

### **功能配置**
- **设置壁纸** 
- 已预设纯黑背景；
- 图片：选择图片设置成壁纸；
- 视频：选择视频设置成壁纸；
- **主题配色**
- 日落：06:00-17:50亮色；
- 亮色：始终保持亮色主题；
- 暗色：始终保持暗色主题；
- 系统：根据手机主题切换；
- 后期可能适配不同地图去调整主题；
- **手机熄屏**
- 由于投屏不可锁屏；
- 熄屏后可有效的节省电量；
- 熄屏后可使用手机开关机两次后点亮屏幕；
- 设置面板：
	- 摇一摇亮屏； 
	- 无操作自动熄屏；

### **应用管理**
- **系统应用** - 字面意思
- **隐藏应用** - 字面意思
- **应用通知** - 迁移到此处
- **默认地图**
	- 内置部分常用地图；
	- 选中可以设置默认地图；
- **应用设置** - 添加后可针对设置
	- 应用缩放：在原DPI基础上浮动偏移；
- **窗口悬浮**
	- 全屏：最底层显示；
	- 悬浮：悬浮在全屏上，并按照窗口比例显示；
	- 填充：悬浮在全屏上，并填充剩余空间显示；
	- **注**：非地图类应用都是悬浮模式打开；

### **其他设置 - Hi时刻**
- **音频模式** - 默认蓝牙模式；    
- **布局调整** - 点击展开详情；
	- 布局模式 - 设置Dock位置；
	- 首页透明 - 设置未打开应用透明效果；
	- 音乐卡片 - 设置Dock显示音乐卡片；
	- 快捷功能 - 调整Dock栏快捷按钮功能；
		- 车机：返回系统车机界面；
		- 熄屏：设置手机息屏处理；
		- 语音：唤起语音识别并处理指令；
		- 镜像：显示手机镜像效果到车机；
	- 置分辨率：纠正识别车机分辨率错误；
	- 布局缩放 - 设置布局大小，缩放Dock
- **语音模块** - 配置语音开关和设置；
	- 聆听时长 - 设置聆听语音时长；
	- 具体使用：[Hi时刻-v3.1.7 支持语音](https://mp.weixin.qq.com/s?__biz=MjM5OTkyNjY5Mg==&mid=2247483959&idx=1&sn=521cf0867d5ab6c8cfd15116626d5ffb&scene=21#wechat_redirect)

- **手势预设**
	- 手势轨迹"V"，配置根据箭头指向；
	- 默认支持四个方向，上下左右；
	- 预设功能：
    	- 全屏：应用切换成全屏模式；
        - 填充：应用尺寸填空空白区域；
        - 退出：结束应用进程，音乐软件忽略；
        - 返回：触发应用的返回操作；
        - 首页：回到首页，类似点击首页按钮；
        - 菜单：唤起应用的二级菜单；
        - 收藏：唤起地图应用的快捷导航地址；
        - Dock：隐藏底部或左侧Dock栏；
- **窗口比例**
	- 悬浮应用的宽高比；
	- 非地图类应用都是悬浮模式；
- **流转帧率**
	- 30、60可选；
- **按键映射**
	- 新增操作
	- 点击编辑框，按下车机按键，车机端提示键码；
	- 目前支持操作：上一曲、下一曲、打开应用；

# 车机端
### **在线壁纸**
- 首页右下角“刷新”图标打开在线壁纸界面；
- 点击想替换的壁纸，点击即可更新壁纸；
- 可公众号上传壁纸，待审核后同步出现；

### **Dock栏**
- **首页按钮**
- 分屏：切换到全屏应用；    
- 主页：切换到主页显示；
	- 长按：切换应用列表页；
- 隐藏：隐藏当前悬浮应用和壁纸集；
- **快捷功能**
- 长按：触发更新功能按钮；
- 车机：返回到原车机界面；
- 息屏：切换手机息屏或亮屏；
- 语音：触发语音聆听并执行指令；
- 镜像：打开和隐藏手机镜像应用；
- 录屏：录制车机视频到相册（默认、无线）；
- **音乐栏**
- 显示当前播放的音乐或有声小说；
- 触摸切换播放状态；
- **应用栏**
- 点击操作：
	- 按照配置打开应用（全屏、悬浮、填充）；
	- 切换显示状态（悬浮、隐藏）；
- 长按操作
	- 强制使用悬浮方式显示；
	- 悬浮、填充的应用会弹出二级菜单；
		- 返回：触发返回操作；
		- 全屏：把当前应用切换成全屏；
		- 填充：把当前应用以填充方式显示；
		- 退出：退出当前应用（非音乐强杀）；
- **快捷功能栏**
- 显示摘要日期信息；
- 车机：返回原车机；
- 截图：截取当前显示并保存到相册；
- 主题：切换深浅主题模式；
- 熄屏：手机黑屏（非锁屏）；
- 音量条：滑动调整音量大小；
### **通知栏**
- 左上角显示通知内容；
- **系统提示**：显示提示，如：壁纸、语音等；
- **应用通知**：显示应用通知内容，点击会跳转到应用；
### **其他交互**
- 首页上滑动显示全部应用；
- 点击悬浮应用的百条也可以展开二级菜单；
- 地图应用，点击收藏图标显示录入的地址；
- 拖动悬浮条至对应引用区域，可重排应用；
